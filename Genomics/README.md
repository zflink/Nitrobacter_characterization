1. `Extract_operons.ipynb` extracts nos and nxr/nar operons and sequences from the genbank files in the `data/` folder.
2. [Clinker](https://github.com/gamcil/clinker) was used to create operon synteny figures from the extracted operon genbank files using default parameters.
3. Extracted gene sequences were used to build phylogenetic trees using MEGA11.
